# Courage+ 1.2.0 — что нового

Сборка 2026-09-21. Предыдущая выданная сборка — **1.1.0** (2026-09-18). Обновление ставится поверх
(`install-to-hu.bat` / `.sh`), настройки, привязка Telegram, история «Авто» и раскладка руля
сохраняются, ПИН вводить заново не нужно.

## Главное

- **Установка APK · проба** — новая вкладка (видна в режиме разработчика: семь нажатий по
  заголовку «Courage+»). Ставит приложение из файла через отдельный установщик, который нужно один
  раз поставить с компьютера; без него кнопка «Установить» честно останавливается. Файл берётся
  **из Telegram** (отправьте `.apk` боту в привязанный чат, до 20 МБ — основной путь), из «Загрузок»
  или с флешки; карточка показывает пакет, версию, «уже стоит», размер и проверку файла. Дальше —
  системный диалог подтверждения, тихой установки нет. ⚠️ На машине не проверялось; на
  эмуляторе — только фронт (системный выбор файлов на этой системе не поддерживается, поэтому
  Telegram первым).
- **Авто** — полосы скорости короче (<40 · 40–60 · >60), правки метрик по съёму окна «С зарядки».

## Папка `dist/`

Старый замороженный релиз 0.17.1 удалён из репозитория — на флешку идёт только `dist-1.0`.

# Courage+ 1.1.0 — что нового

Сборка 2026-09-18. Предыдущая выданная сборка — **1.0.13** (2026-09-11); ниже всё, что
изменилось с неё. Обновление ставится поверх (`install-to-hu.bat` / `.sh`), настройки, привязка
Telegram, история «Авто» и раскладка руля сохраняются, ПИН вводить заново не нужно.

## Главное

- **Условия использования и отказ от ответственности** — на экране замка, первой карточкой.
  Программа предоставляется «как есть»; разработчик не несёт ответственности за последствия
  установки и использования, всю ответственность несёт пользователь. **Ввод ПИН означает
  согласие с условиями** — та же фраза стоит над клавиатурой ПИН. Полный текст — в `DISCLAIMER.md` рядом с этим файлом. Уже открытых установок это
  не касается: замок повторно не появляется.
- **Telegram** — привязка чата в «Настройках» один раз для всего приложения: QR-код
  (`t.me/<бот>?start=<код машины>`) или код руками. Через неё приходят тревоги сторожа, файлы
  «Авто» и свой звук для «Сигнала».
- **Авто: окно «С зарядки»** — метрики и графики считаются от конца последней зарядки: сколько
  проехали, сколько ушло, стоянки и поездки с того момента. Окна «15 дн» и «30 дн» убраны
  (тяжёлые для головного устройства и редко нужны); остались 1 ч … 7 дн и «С зарядки».
- **ADAS-пакеты в «Настройках»** — новая секция: активация платных пакетов помощи водителю
  напрямую на блоке ADAS, минуя магазин и китайское облако (которые вне КНР недоступны).
  Доступны четыре: **ISLC** (Intelligent Speed Limit Control — контроль скорости по знакам),
  **TLC** (Traffic Lane Control — управление в полосе), **ELK** (Emergency Lane Keeping —
  аварийное удержание в полосе), **ESA** (Emergency Steering Assist — помощь при экстренном
  рулении).
  Порядок жёсткий: сначала кнопка **«Проверить канал (безопасно)»** — она отправляет команду
  «оставить всё как есть» и ничего не активирует; список пакетов открывается только после
  зелёного результата и только на стоящей машине (селектор в P); ELK и ESA — под второй
  галочкой подтверждения. ⚠️ **Активация необратима** — выключить пакет обратно нельзя.
  ⚠️ На машине секция ещё не проверялась: на этом обновлении — **только проверка канала**,
  результат (зелёный/красный, с Wi-Fi и без) сообщить автору, активацию не трогать.
- **Ассистент: распознавание через интернет** — при подключённом Wi-Fi та же запись фразы
  разбирается интернет-сервисом, что точнее на числах и редких словах; без сети или при
  молчании сервиса работает встроенное распознавание, как раньше. По умолчанию выключено —
  галочка «Распознавать через интернет, когда есть сеть» на экране ассистента. ⚠️ В этой сборке
  ключ сервиса не вшит — без него галочка ничего не меняет.
- **Ассистент: длинные фразы дослушиваются целиком** — обрывок распознавания больше не
  закрывает сессию, фраза собирается до паузы.

## По инструментам

### 🎙 Ассистент
- Голосом **«включи сторожа» / «выключи сторожа»** — штатный сторожевой режим (сентри).
- Распознавание через интернет и дослушивание фраз — см. «Главное».

### 🚗 Авто
- Окно «С зарядки»; окна «15 дн» и «30 дн» убраны.
- **«.csv в Telegram»** — выгрузка окна одним нажатием в привязанный чат, без ноутбука.
- Метрики пересчитываются только когда пришли новые данные — головное устройство больше не
  греется на длинных окнах.
- Зарядки — своя графа: рост заряда на стоянке не считается расходом и не портит «%/ч».

### 🚨 Сигнал
- **Свой mp3 из Telegram**: отправьте файл боту и нажмите «Получить из Telegram» — звук
  появится в списке плитками, галочкой ставится на кнопку трубки.
- Звук на кнопке трубки работает **и при закрытом Courage+**, пока включён рулевой мост.
- Сирена сторожа больше не глушит звук трубки.

### 🕹 Руль
- Вызов ассистента с руля при выключенном ассистенте честно отвечает «выключен», а не молчит.

### ⚙️ Настройки
- **Telegram** — привязка чата (см. «Главное»), «Проверить» и «Отвязать».
- **ADAS-пакеты** — новая секция, см. «Главное»: проверка канала → список ISLC/TLC/ELK/ESA →
  активация (необратима). На этом обновлении — только «Проверить канал (безопасно)».
- Пешеходный звук — без изменений: одна галочка, снял — звук возвращается сразу.

### 👤 Личный кабинет
- Установщик теперь выдаёт нужное право сам — активация кабинета больше не упирается в
  «право выдаёт установщик».

### Сентри (сторож)
- Тревоги уходят в чат, привязанный в «Настройках»; своё поле chat_id на экране сторожа убрано.
- Сторож и запись «Авто» не падают при остановке на ходу; очередь сообщений пишется атомарно.

## Установка

1. Скопировать папку `dist-1.0` на флешку (или на ноутбук с ADB).
2. Windows: `install-to-hu.bat`; macOS/Linux: `install-to-hu.sh`. Скрипт ставит APK поверх
   прежней версии и выдаёт права.
3. Открыть Courage+ на головном устройстве. Новые установки покажут замок: прочитать условия,
   продиктовать автору код машины, ввести ПИН.

## Что проверить на машине в первую очередь

- «Авто» → окно «С зарядки»: подпись графика «с зарядки <дата время>» и метрики от этого момента.
- «Настройки» → «ADAS-пакеты» → «Проверить канал (безопасно)» — только проверка, без активации.
- «Ассистент» → длинная фраза с паузой — дослушивается целиком.
- «Сигнал» → свой mp3 через Telegram → на кнопке трубки при закрытом приложении.

## Известные ограничения

- На охране прошивка гасит Wi-Fi головного устройства: сообщения сторожа копятся и уходят
  после открытия машины.
- Распознавание через интернет требует Wi-Fi (хотспот телефона) и ключ сервиса.
- Реальное состояние пешеходного звука приложение прочитать не может — сверять по слуху.
