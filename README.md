# Courage+ — сборки для VOYAH Courage

Здесь лежит готовая к установке сборка **Courage+** — независимого приложения для головного
устройства VOYAH Courage (岚图知音), ввезённого вне КНР: китайское облако и магазин на такой машине
недоступны, и часть возможностей ГУ остаётся закрытой. Courage+ возвращает их без облака.

Текущая версия — в [`version.json`](version.json); что изменилось — в
[`RELEASE-NOTES.md`](RELEASE-NOTES.md).

> ⚠️ Приложение управляет настоящей машиной. Прочитайте [`DISCLAIMER.md`](DISCLAIMER.md) до
> установки: программа предоставляется «как есть», всю ответственность за её использование несёт
> пользователь. Ввод ПИН на экране замка означает согласие с этими условиями.

## Что умеет

| Инструмент | Что делает |
|------------|------------|
| 🔒 Доступ | замок на входе: код машины → ПИН от автора; пока ПИН не введён, приложение ничего не запускает |
| 👤 Личный кабинет | вход в штатный личный кабинет без китайского облака, несколько пользователей |
| 🕹 Руль | рулевой медиа-мост: «трек вперёд/назад» с руля доходят до стороннего плеера (Яндекс Музыка и другие); своя команда или звук на кнопку |
| 🎙 Ассистент | голосовое управление машиной по-русски — «Hi VOYAH» или кнопка на руле; сцены (одна фраза — несколько действий), свои команды, распознавание без интернета |
| 🚗 Авто | живые данные с шины машины, запись в фоне, графики и метрики (расход, поездки, стоянки, «с зарядки»), выгрузка `.csv` |
| 🚨 Сигнал | выбранный звук наружу по кнопке трубки на руле; встроенные сирены и свой mp3 |
| ⚙️ Настройки | то, что прошивка сбрасывает на каждом старте, а Courage+ восстанавливает сам: пешеходный звук (AVAS), привязка Telegram, активация ADAS-пакетов |
| Сентри | сторож: тревоги охранного режима приходят в Telegram, при высоком уровне — сирена наружу |

Подробности по каждому инструменту и известные ограничения — в [`RELEASE-NOTES.md`](RELEASE-NOTES.md).

## Установка на машину

Понадобится ноутбук и кабель **USB-A — USB-A**.

1. Скачайте репозиторий целиком («Code → Download ZIP») и распакуйте — либо скопируйте папку на
   флешку.
2. На головном устройстве включите **USB Debugging** (инженерное меню).
3. Соедините ноутбук и ГУ кабелем, на экране машины подтвердите отладку.
4. Запустите установщик из распакованной папки:

```bat
rem Windows
install-to-hu.bat
```

```bash
# macOS/Linux — adb нужен в PATH (brew install android-platform-tools)
./install-to-hu.sh
```

Скрипт дожидается ГУ, снимает блокировку установки, ставит APK (по USB — до минуты) и выдаёт
приложению нужные права. Аргументом можно передать другой файл: `install-to-hu.bat путь\к.apk`.

После установки на экране машины:

1. Откройте **Courage+**. На замке — прочитайте условия, продиктуйте автору **код машины** и
   введите полученный **ПИН**. Там же чеклист: строка «Модель распознавания» должна быть ✅.
2. 🎙 **Ассистент → «Включить»**. Первый запуск распаковывает модель распознавания (несколько
   секунд, статус на экране), затем «готова». Голос вызывается словом «Hi VOYAH» или кнопкой
   голосового помощника на руле.
3. Для рулевого моста — выдать доступ к уведомлениям кнопкой на его экране.

Проверять новые функции — только на стоящей машине: селектор в P, стояночный тормоз, у проёмов
никого.

## Обновление

Новая версия ставится **поверх** тем же `install-to-hu.bat` / `.sh`: настройки, привязка Telegram,
история «Авто» и раскладка руля сохраняются, ПИН вводить заново не нужно.

Свежие сборки умеют находить обновление сами: экран «Обновления» читает `version.json` из этого
репозитория, скачивает `Courage-Plus.apk`, сверяет размер и `sha256` и предлагает установить. Для этого ГУ
нужен интернет (хотспот телефона) и один раз поставленный с компьютера установщик пакетов —
подробности в `RELEASE-NOTES.md`. Через Telegram обновление не пройдёт: APK больше 20 МБ.

## Права, которые выдаёт установщик

Установщик выдаёт их сам, руками ничего делать не нужно — список для понимания, что и зачем:

- **Поверх других окон** — плашка «слушаю» ассистента вне экрана приложения;
- **Микрофон** — распознавание речи;
- **Уведомления** — уведомления фоновых служб (рулевой мост, ассистент, запись «Авто»);
- **Видео из медиатеки** — ролик регистратора к тревоге сторожа;
- **Системные настройки** — активация кабинета и режим правого блока руля.

## Вопросы и обратная связь

Исходный код закрыт; ПИН к машине, ключи сервисов и разбор проблем — у автора. Если что-то не
работает: включите режим разработчика семью нажатиями по заголовку «Courage+», на экране
инструмента появятся журналы и кнопки их отправки.
