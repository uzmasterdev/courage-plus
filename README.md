# dist-1.0 — Courage+ 1.0: один APK и загрузчик на ГУ

Мажорная ветка **1.x** (текущая сборка — 1.2.0). Папка `dist/` релиза 0.17.1 удалена 2026-09-21
(история в git); всё собирается сюда. На флешку копируется **только `dist-1.0`**.

С 2026-09-04 **модель распознавания едет внутри APK** и распаковывается сама при первом запуске
сервиса ассистента (несколько секунд). Отдельных заливок моделей и скриптов `push-*-model` больше
нет: на машине они дважды срывались — скрипт отчитывался «модель на месте», а приложение видело
`NOT_FOUND`, и текстовые файлы модели приезжали с CRLF после `core.autocrlf` на Windows
([итоги 2026-09-03](../docs/results/20260903/test-notes-20260903-0171.md)). Голос ответа (TTS)
из 1.0.0 снят решением владельца 2026-09-04 — [`../docs/tts.md`](../docs/tts.md).

## Как поставить на машину

Подготовка: включить **USB Debugging** (инженерное меню), соединить ПК и ГУ кабелем **USB-A—USB-A**,
подтвердить отладку на экране авто. На флешке — папка `dist-1.0\` целиком.

```bat
rem Windows — из папки dist-1.0
install-to-hu.bat
```

```bash
# macOS/Linux — adb нужен в PATH (brew install android-platform-tools)
./install-to-hu.sh
```

Скрипт дожидается ГУ, снимает OEM-блок установки, ставит APK `install -r -g` (~56 МБ, по USB до
минуты) и выдаёт права: `SYSTEM_ALERT_WINDOW` (нужен плашке «слушаю»), `RECORD_AUDIO`,
`READ_MEDIA_VIDEO` (ролик регистратора к тревоге сторожа), `POST_NOTIFICATIONS` (уведомления
foreground-сервисов, runtime-право SDK 33 — иначе при установке без `-g` их не видно),
`WRITE_SECURE_SETTINGS` (активация кабинета;
`install -g` development-права не выдаёт, поэтому явный `pm grant` — с 1.0.14) и appops
`WRITE_SETTINGS` (режим правого блока руля). Больше он ничего не заливает. Аргументом можно передать другой `.apk`: `install-to-hu.bat путь\к.apk`.

После установки — замок (код машины → ПИН от автора), там же чеклист: строка «Модель
распознавания» должна быть ✅ «в составе APK». Дальше 🎙 «Ассистент» → **«Включить»**: первый запуск
после установки распаковывает модель (статус «распаковываю модель из APK», несколько секунд), затем
«готова». Голос вызывается словом «Hi VOYAH» или кнопкой на руле. Старая копия модели 0.17.x в
`Android/data/…/files/vosk/ru` при этом удаляется сама.


## История версий

Новое сверху; подробности каждого инструмента — в его документе в `../docs/`.

- **1.1.0** (сборка 2026-09-18; минорная версия по решению владельца, `versionCode` 1100 = major·1000 + minor·100 + patch; поглотила промежуточную 1.0.15 того же дня) — **условия использования и отказ от ответственности на экране замка** (первая карточка, шесть пунктов; ввод ПИН = принятие условий, та же фраза над клавиатурой), в «Авто» окно **«С зарядки»** (метрики и графики от конца последней зарядки; «15 дн» и «30 дн» убраны), **«ADAS-пакеты» в «Настройках»** (активация платных ADAS-пакетов напрямую, минуя магазин и облако: сначала безопасная проверка канала, список пакетов ISLC/TLC/ELK/ESA только после неё, активация **необратима** и только на стоящей машине; ⚠️ на машине не была — план прогона `docs/plan/next-steps.md` §1.4), **распознавание через интернет** в ассистенте (облачный разбор той же записи поверх Vosk, по умолчанию выключено; ⚠️ в этой сборке ключ сервиса не вшит — `asr.properties` нет, свой ключ вводится в режиме разработчика), обрывки фраз Vosk больше не закрывают сессию — фраза дослушивается целиком.
- **1.0.14** (сборка 2026-09-16) — **привязка Telegram в «Настройках»** (QR `t.me/<бот>?start=<код машины>` или код руками, общая на всё приложение), **свой mp3 для «Сигнала» из чата бота** («Получить из Telegram»; очередь бота листается страницами — при забитой очереди файл раньше не доходил никогда), **CSV «Авто» в Telegram**, голосовые **«включи / выключи сторожа»** (штатный переключатель сентри), **звук на кнопке трубки работает и при закрытом Courage+**; по код-ревью 2026-09-15: установщик выдаёт `WRITE_SECURE_SETTINGS` (активация кабинета больше не упирается в «право выдаёт установщик»), метрики «Авто» пересчитываются только при новых данных (окно 30 дн больше не греет ГУ), сирена сторожа не глушит звук трубки, ассистент с руля при выключенном тумблере честно говорит «выключен».
- **1.0.13** (сборка 2026-09-11) — в «Авто» **метрики по взаимосвязи сигналов**: график «SOC ↔ пробег» по км одометра, «Расход окна» (кВт·ч/100 км, км на 1 %, доли движения и стоянок), «Поездки» и «Стоянки» сессиями (средняя скорость поездки, расход, утечка на стоянке %/ч), графики по времени свёрнуты под «Подробнее»; **полоса экспериментальных вкладок по умолчанию спрятана** — показать/спрятать семь нажатий по заголовку «Courage+» (Config Viewer и карточка канала доставки спрятаны флагами); по код-ревью и прогону 2026-09-11: ассистент различает шторку/люк/окно/багажник и не зажимает число больше 100, поле токена бота маскируется, сторож сентри и запись «Авто» не падают при остановке на ходу; вкладка «互联 · проба» (1.0.12, пробник штатного файлообмена VoyahShare) **удалена** — на машине себя не оправдала; из ассистента убраны **вопросы о машине** (13 команд, ответ штатного шёл по-китайски) — 363 команды.
- **1.0.11** — вкладка **«Сентри»** (сторож: сервис слушает тревоги сторожевого режима и шлёт их в Telegram — бот вшит в сборку; привязка чата теперь в «Настройках» (QR `t.me/<бот>?start=<код машины>` или код машины руками), общая на всё приложение; с именем и размером ролика, сам файл прошивка не отдаёт; сирена наружу при высоком уровне по тумблеру; ✅ на машине 2026-09-10: тревоги доходят, но **на охране прошивка гасит Wi-Fi ГУ** — сообщения копятся в очереди и уходят после открытия машины), пробник «Сентри · проба» (прогнан 2026-09-09) спрятан.
- **1.0.10** — вкладка «Сентри · проба» (установщик выдаёт `READ_MEDIA_VIDEO`); **«Настройки»** в шапке (значок шестерёнки): настройки машины, которые прошивка сбрасывает на каждом старте ГУ, а Courage+ восстанавливает сам; пока одна — **пешеходный звук** (бывшая вкладка): одна галочка, снял — звук возвращается сразу, журнал и кнопки убраны; **«Сигнал»** в шапке (значок маячка, бывшая вкладка «Звуки»): в выборе динамика только пути C и C1, **девять встроенных сирен** (синтез: wail, yelp, hi-lo, скорая, пожарная; записи Pixabay: две полицейские и пожарная; и прежняя) — громкость и шов петли на машине не проверены, план «громче наружу» — `docs/plan/outdoor-loudness.md`.
- **1.0.9** — **«Авто»** в шапке вместо «Энергии» (значок машины): живые данные с шины машины (подписка на ValServer, канал подтверждён 2026-09-08), фоновый сервис пишет каждое изменение **выбранных** сигналов в базу на ГУ (кнопка «Что записывать», каталог на все 80 событий шины) и работает без экрана, одометр из хранилища машины, графики сеткой с выбором параметра карандашом, полный экран и значение в точке касанием, экспорт `.csv`; «Энергия» и вкладка «Данные машины · проба» убраны (пробник спрятан флагом); ⚠️ сервис, база и графики на машине не проверены.
- **1.0.8** — вкладка «Данные машины · проба» (три источника, все живые по прогону 2026-09-08).
- **1.0.7** — **несколько пользователей** в кабинете (реестр + броадкаст на приёмник usercenter, переключение офлайн).
- **1.0.6** — **пешеходный звук** гасится и после пробуждения ГУ из сна (второй триггер на включение экрана; на машине не проверен), **звуки** по умолчанию путь C (наружу и в D, взвод усилителя свистом; C1 переключается), **«Автоматизация · проба»** переписана под снятый формат движка сцен и сама заводит сцены-детекторы (`UCIE<id>`) — всё это ждёт машины; всё, что было в 0.17.1, плюс **модель Vosk внутри**, **словарь распознавания только из слов команд** (точнее в шуме, тумблер), **сцены** (одна фраза — несколько команд штатному подряд, в редакторе своих команд), **свои команды с числом**, **пульт на плашке** (недавние команды и «Отменить» одним касанием), **своя команда или сцена на кнопке руля**, **вопросы о машине** (запас хода, заряд, шины, пробег, расход — ответ штатного по-китайски, формулировки не проверены), **«Энергия»** в шапке (та же история расхода, что на штатном «Trip statistics», только чтение; с 1.0.3 — график как на штатном экране, кВт·ч/100 км, средний и разброс по окну, точки новые сверху), **слайды «Что умеет Courage+»** на экране замка, вкладка **«Звуки»** (сирена на кнопке трубки пока нажата и свой звук на кнопку руля, с попыткой вывести наружу — куда уходит звук, проверить на машине).
- **1.0.5** — **канал доставки** на экране ассистента (броадкаст / сцена / авто) и вкладка «Сцены» для снятия словаря входа №1 — задел под прошивки 2.5.2+, где броадкаст отбрасывается; по умолчанию всё как раньше.
- **1.0.4** — **376 команд вместо 159** по каталогу движка (зарядка, режимы езды, круиз и помощь водителю, внешний свет, цвета подсветки, экран и система, медиа-режимы, присмотр; перестроение и автопарковка с красной пометкой; замков, подвески и лючка зарядки нет — решение владельца), китайские фразы новых команд собраны по образцу и ждут машины. По журналу прогона 2026-09-07: мусорное числительное в начале фразы («одна включи музыку») режется, счётное число не прячет «на пятьдесят процентов», «выключи музыку» = пауза, «левое/правое окно» = водителя/пассажира; в истории у каждой отправки «№N · +Δt · повтор» и ответ NLU штатного — для разбора «перестал исполнять» без ноутбука; в журнале тайминги слов Vosk. Вне экрана ассистент слушает через плашку «слушаю» — единственный обход, сработавший на машине; выбор режима и вкладка «Навигация» убраны (служба спец.возможностей на этой прошивке не привязывается).
## Обновление APK

`./build.sh` (release с R8, ключ из `keystore.properties`) собирает пакет и копирует его в эту
папку — `Courage-Plus.apk`. Модель лежит в `app/src/main/assets/vosk/ru` (та же
`vosk-model-small-ru-0.22`, что была в удалённой `dist/vosk/ru`).
⚠️ APK с моделью — около 56 МБ; потолок GitHub — 100 МБ на файл, расширения модели в `noCompress`
не дописывать (`app/build.gradle`).
