# CLAUDE.md

## Что это

**Публичный** репозиторий-витрина сборок Courage+ (`dev.uzmaster.ucinjector`) — Android-приложения
для ГУ VOYAH Courage. Исходного кода здесь нет и не будет: он в отдельном приватном репозитории.
Аудитория — владельцы машин и само приложение: экран «Обновления» читает отсюда `version.json`
и качает `Courage-Plus.apk` по адресу `raw.githubusercontent.com/uzmasterdev/courage-plus/master/…`.

Репозиторий заполняется **скриптом** из приватного проекта (`tools/publish-dist.sh`): содержимое
папки `dist-1.0/` копируется сюда один в один (`rsync --delete`), коммит `Courage+ <версия>`,
push в `master`.

## Что откуда — и что можно править

| Файл | Владелец | Правка здесь |
|------|----------|--------------|
| `Courage-Plus.apk`, `version.json` | сборка (`build.sh` приватного репозитория) | ⛔ никогда: `size`/`sha256` в манифесте должны совпадать с файлом байт в байт, иначе приложение отвергнет обновление |
| `RELEASE-NOTES.md`, `DISCLAIMER.md` | приватный репозиторий (`dist-1.0/`) | ⛔ затрётся следующей публикацией — править там |
| `install-to-hu.bat`, `install-to-hu.sh`, `adb/win/` | приватный репозиторий (`dist-1.0/`) | ⛔ то же |
| `README.md`, `CLAUDE.md`, `.gitignore`, `.gitattributes` | **этот репозиторий** | ✅ единственное, что живёт здесь; скрипт публикации их не трогает |

## Правила

- **Ветка `master`, файлы в корне, имена `Courage-Plus.apk` и `version.json`** — адрес вшит в
  приложение. Не переименовывать, не переносить в подпапки, не менять ветку.
- **Ни одного секрета и ни одной внутренней подробности.** Это публичный репозиторий: сюда не
  попадают токены и ключи, ссылки на приватные документы (`docs/…`, `../…`), имена штатных
  пакетов/сервисов прошивки, разборы прогонов. README — для владельца машины: только «что делает»
  и «что сделать».
- **`install-to-hu.bat` — строго CRLF**, хранится байт в байт (`*.bat -text` в `.gitattributes`,
  чтобы «Download ZIP» и raw-ссылки отдавали CRLF): с LF `cmd` выходит молча. Не пересохранять
  редакторами, которые нормализуют переводы строк; перед коммитом — `file install-to-hu.bat`.
- **APK ≤ 100 МБ** — потолок GitHub на файл, сейчас ~56 МБ.
- `.idea/`, `.DS_Store`, `*.zip` — не коммитить (в `.gitignore`).
- Язык всего — русский.

## Проверка перед публикацией

```bash
shasum -a 256 Courage-Plus.apk          # == "sha256" в version.json
stat -f %z Courage-Plus.apk             # == "size" в version.json
file install-to-hu.bat                  # … with CRLF line terminators
```

Публикация новой сборки — только `./build.sh` → `./tools/publish-dist.sh` в приватном
репозитории; руками файлы сборки сюда не класть.
